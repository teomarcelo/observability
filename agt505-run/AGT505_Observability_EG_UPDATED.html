Exercise 2: Interact with an Agent

Task 1 — Create agent from script

  1. App Launcher → Agentforce Studio → Agents.
  2. New Agent menu → New from Script.
  3. Paste script from sforce.co/ProntoAgent → Create Agent.
  4. Preview → Select User → EinsteinServiceAgent User → Save.

Task 2 — Test and activate

  1. Preview in Live Test Mode. Reset between turns.
  2. Utterances: fusion bites restaurant; speak to an agent; help with info about a store.
  3. Save → Commit Version → Activate → exit Builder.
Exercise 3: Experience Agentforce Observability

Task 1 — Analytics (Service Agent)

  1. Agentforce Studio → Analytics. Agent Type = Service Agent.
  2. Filter bar: Agent, Timeframe, Channel, Modality (count these four).
  3. Explore Overview → Agent Performance / Aggregated Effectiveness Metrics (Success, Engagement, Abandon, Escalation, Deflection).
  4. Explore category pills including Custom Scorers (may show Task Resolution / Einstein Feedback disabled).
  5. Open Performance Insights for breakdowns (replaces EG “Agent Effectiveness” top-tab framing).

Task 2 — Insights (via Sessions / Performance Insights)

SP26v1 EG said Optimization → Insights. In this org, use Analytics → Performance Insights and the Sessions processing banner instead of a separate Insights page.

Task 3 — Sessions & Intents

  1. Select Sessions & Intents.
  2. Processed Sessions may be empty / processing; open Unprocessed Sessions to see test traffic.
  3. Open a Session ID for the chat/trace detail when available.
